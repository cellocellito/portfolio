# CELLO.SYS — portfolio of Marcelo Ribeiro Lima

Personal portfolio. Pixelscape × cybercore × liquid glass — see [design.md](design.md)
for the full design system (palette, type, motion, textures). Every visual decision in
the code traces back to that file.

## Stack

Vite + vanilla TypeScript + CSS. GSAP (ScrollTrigger, SplitText) + Lenis for motion,
three.js for the hero's dithered shader atmosphere (lazy-loaded, static fallback),
Lottie light + [useAnimations](https://useanimations.com/) data for the social icons
(lazy-loaded, pixel-SVG fallback). No framework — it's a content site.

## Develop

```bash
npm install
npm run dev        # http://localhost:5173
```

## Build & deploy

```bash
npm run build      # type-checks, outputs dist/
npm run preview    # serve the production build locally
```

Deploys to **Vercel with zero config**: framework preset "Vite", build command
`npm run build`, output `dist`. Nothing else needed.

### After you have a domain

Open Graph scrapers want absolute image URLs. In `index.html`, change

```html
<meta property="og:image" content="/og.png" />
```

to your absolute URL (e.g. `https://yourdomain.com/og.png`), and consider adding
`og:url` + a canonical link. The OG image itself is generated by
`scripts/gen-og.ps1` (Windows/PowerShell) into `public/og.png`.

## Accessibility & performance notes

- Everything works without JavaScript: all project content ships in the HTML,
  expanded; JS only adds the accordion, motion, and atmosphere.
- `prefers-reduced-motion` disables Lenis, all GSAP choreography, the shader
  (static dither fallback), the grain jitter, and the footer ticker.
- Fonts: 3 self-hosted latin-subset woff2 files (~45KB total), preloaded.
- three.js is an async chunk loaded on idle after `load` — it never blocks
  content and is excluded from the core JS budget by design.
