## Context

This is my capstone for Systems Analysis and Development at FATEC Botucatu: one WhatsApp chat in front of three specialists, one for Gmail, one for Google Calendar and one for a finance tracker in Notion.

I picked those three because all of them have free APIs, and WhatsApp connects through Evolution API.

## What I built

A router agent reads every message and hands the request to a specialist: one for Gmail, one for Google Calendar, one for the Notion finance tracker. Voice notes go through Whisper first. Long-term memory lives in Qdrant, and the agent can search the web when it needs something current. n8n orchestrates it all, with Supabase and Redis, self-hosted with Docker. The model is GPT-5-mini.

## Decisions

- **A router in front of specialists, instead of one agent with every tool.** Splitting the work keeps a single agent from carrying all of it, and the tasks come out better this way.
- **Self-hosted with Docker.** It costs nothing, and running it myself is practice.

## What broke

What I remember breaking is the way the assistant's personality was injected from Supabase. I changed that part later.
