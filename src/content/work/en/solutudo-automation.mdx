## Context

Customer service and the back office at Solutudo Brasil handled part of their daily work by hand. I joined as an automation developer in January 2026.

## What I built

Over six months I built more than 20 n8n workflows that ran in production. Together they removed about 6 hours a day of manual work: roughly 4 in customer service and 2 in the back office.

- An Instagram pipeline that turns a comment into a direct message.
- WhatsApp support automation on OpenAI and Gemini, wired through the Meta Graph API and Evolution API.
- Back-office integrations over REST APIs and SQL, with Redis in the stack.
- Prompt engineering for B2B accounts, and troubleshooting whenever an integration became the bottleneck.
- A dashboard that showed every running automation, working next to a workflow guardian that reported failures.

## Decisions

- **n8n instead of custom code.** Problems are easier to diagnose in n8n, and the flows are easier to maintain.
- **Two model providers.** To save money: Gemini's free tier handled the basic tasks and OpenAI the more complex ones.
- **Evolution API next to the Meta Graph API.** Meta's API ran Solutudo's own WhatsApp and Instagram automations, clients' Instagram accounts included. Evolution API ran the WhatsApp automations we built for clients.

## What broke

While I was testing a WhatsApp automation for Solutudo, it sent a message to about 20 contacts in one second. I corrected the flow, and it never happened again.
